ƒ Expressions ↔ circuit

One NAME = expression per line. Operators: AND OR NOT XOR NAND NOR XNOR or symbols * + ! ^ and a trailing ' (A' = NOT A). Constants 0/1. Later lines can use earlier names.

📘 Lessons

State machine designer

Describe a machine as a table. It becomes D flip-flops and minimized logic, wired up with a clock. First state listed = reset state. Format: STATE inputs -> NEXT / outputs (use x for don't-care).

Verilog export / import

Export writes the current circuit as a Verilog module (gates, constants, flip-flops, latches, mux, decoder). Import reads gate primitives (and, or, not…) and assign with & | ^ ~; buses, feedback and procedural code are not supported.

Create a challenge

Your current circuit defines the target: its switches become the challenge inputs and its LEDs the outputs (combinational circuits only). Learners get a blank scaffold and must match the behaviour.
